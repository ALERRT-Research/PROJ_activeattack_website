## Gotchas met

- **Quarto re-parses raw HTML tables** from `knitr::asis_output()` into its own tables: Bootstrap classes appear
  (`table table-striped small`) and nested markup in cells (the `<ul>` of levels) is flattened to bullets. Wrap the
  chunk in `::: {html-table-processing="none"}`.
- Two inline R chunks back to back (`` `{r} a``{r} b` ``) leave the second unevaluated; build the sentence in R.
- Inline R output is verbatim text: markdown `*italics*` in a string shows its asterisks. Emit HTML via `asis_output`.
- **`ty()` in `fact_sheet_pdf.R` never escaped anything**: in TRE the `\]` inside the bracket class closes it, so the
  pattern matched only a literal "`~=]" tail. Fixed with `perl = TRUE` in both PDF builders. The fact sheet PDF was
  not rebuilt (its text has none of the escaped characters), so it is unchanged.
- Typst 0.11 splits a table row across pages; `#show table.cell: it => block(breakable: false, it)` stops it.
- Quarto dashboards inject `bPaginate: false` into every DT (see the download-tab log).
